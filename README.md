# Progetto GeoRust - Gruppo G8

Workspace Cargo con 3 crate:
- `common`: struct condivisi del protocollo
- `server`: backend
- `client`: client dimostrativo (registrazione, invio posizione, messaggi)

## Come avviare

```bash
# Server
cd server
cargo run

# Client (in un altro terminale)
cd client
cargo run
```
